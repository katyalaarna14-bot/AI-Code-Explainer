### AI-Powered Code Explainer, Improver & Optimizer
CodeWise AI is a Generative AI-powered programming assistant designed to
help beginners understand, improve, and optimize their programming code.

The application uses Python, Streamlit, and the Google Gemini API to
analyze code and provide clear, beginner-friendly explanations.

---

## ✨ Features

### 📖 Explain Code
Analyzes programming code and explains:
- What the code does
- How the code works
- Time complexity
- Space complexity
- Important functions
- Important variables

### 🔧 Improve Code
Identifies:
- Possible problems
- Readability issues
- Potential bugs
- Areas for improvement

It also provides an improved version of the code.

### ⚡ Optimize Code
Analyzes code efficiency and provides:
- Inefficiencies in the original code
- Optimization suggestions
- Optimized code
- Time complexity comparison
- Space complexity comparison

### 🌐 Multiple Programming Languages

CodeWise AI supports:

- 🐍 Python
- ☕ Java
- ⚙️ C++
- 🌐 JavaScript

### 📋 Additional Features

- Load Example Code
- Clear Code
- Code Statistics
- Beginner-friendly explanations
- Professional user interface
- Secure API key handling

## 💡 How It Works

```text
User enters programming code
          ↓
Selects programming language
          ↓
Chooses an AI operation
          ↓
Python application creates a prompt
          ↓
Gemini API processes the request
          ↓
Gemini generates the response
          ↓
Streamlit displays the result
